## 社区版与安装器

1.10.1-alpha.1 保留相同 Java 业务代码，移除预置海报二进制、增加标准 Gradle 工程和公开安装准备流程。公开 APK 不自动安装到用户当前设备，因此**本社区 APK 的实际安装、首次无预置海报运行和第二台设备验收均待完成**。

模拟 ADB 回归覆盖只读、安装、恢复、原不存在设置键删除、保留语音和后来新增辅助服务、不兼容型号、包名占用、安装签名失败后停止。模拟不证明真实固件允许这些命令。

公开准备流程校验项目载荷、固定版本 Google 工具和可选官方 Kodi，重建本机 checksums.json。源码 / 发布包隐私检查只覆盖静态可检查项，公开前还需人工审阅明确文件清单。
