# 客厅安装助手

适配固定 Release **1.10.1-alpha.1**，仓库 https://github.com/VictorAgents/livingroom-launcher 。先读 [Windows 操作流程](references/windows-install.md)，再按目标执行，不直接复制底层 ADB 写入命令绕过安装器。

## 目标与授权

区分用户要首次安装、现有客厅更新、检查排障还是恢复。只问缺失信息：目标 IP、是否为 A4093、是否开机并开启 ADB、是否需要 Kodi 和广告/屏保设置调整。

只读检测和电脑端下载可先进行。设备安装将设默认 HOME，启用腾讯根首页 BACK 按键过滤和使用情况访问；默认完整模式还管理已确认广告入口、悬浮窗、屏保及熄屏。清楚说明实际范围；用户已经授权这些功能时继续，不重复索要许可。只说“检查一下”不等于授权修改。

本技能不增加工具权限，不授予 Root、刷机、重启、系统分区写入、账号迁移或公开备份权限。首次电视 ADB 授权由用户完成。无本地工具时只能指导，不能声称已检测或安装。

## 执行

1. 用 `scripts/Get-Release.ps1 -Destination <本机工作目录>` 下载固定 Release PC ZIP 与 SHA256SUMS，校验后解压。保持本机文件，不上传设备标识或备份。
2. 按用户选择运行 `Prepare.ps1`；只要客厅时加 `-SkipKodi`。准备只下载并校验官方依赖，不访问盒子。
3. `Install.ps1 -Device <用户提供IP> -CheckOnly`。确认型号 / API / ABI / 原白名单候选 / 腾讯包 / 包名无占用，不符合即停止。不能临时放宽守卫、改包名、强制卸载或绕过签名。
4. 仅在实际功能已获授权后执行安装。Agent 无交互模式可用 `-AcceptChanges`；不需要 Kodi / 设备设置调整时分别加 `-SkipKodi` / `-SkipDeviceTuning`。检查退出码与错误文本，核实生成的备份位置和回读结果；失败即停，保存本机备份，解释恢复选项。
5. 先确认默认 HOME 和权限回读，再请用户实体遥控器验证 Home、腾讯根首页 BACK、其他应用与语音。ADB input 不能替代辅助服务物理按键验收。需要重启前明确告知并让用户准备；本工具不自动重启。

## 恢复和接续

恢复是单独任务，不能在普通排障时擅自执行。读取用户选定备份路径，先用 `-Restore <path> -CheckOnly` 核对序列号与固件指纹，再在授权后执行恢复。保留其他服务、APK、Kodi数据；不能承诺恢复 APK 版本或整个固件。

会话中断时，在本机留下版本、目标的非敏感代称、已完成阶段、备份位置和下一步；不记录实际序列号、MAC、账号或日志。恢复工作先读回现状，不因中断重新首次安装。不要将备份上传聊天或公开仓库。

最终报告分开说明：下载校验、只读检查、安装/设置回读、物理遥控器、实际重启、用户确认。现有公开实机截图来自 1.10 基线；社区 APK 和第二台原始盒子未有完整验收，不能宣称通用成功。原生开机视频仅只读调查，不在当前功能范围内。
